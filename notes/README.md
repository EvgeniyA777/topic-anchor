# Project Notes

Хранилище рабочих заметок проекта.

## Канон

- Папка: `notes/`
- Имя файла: `YYYY-MM-DD-HHmm-UUID.md`
- Дата/время в имени должны совпадать с `created_at` во frontmatter (`YYYY-MM-DDTHH:MM`)

## Быстрый старт

```bash
./scripts/new-note.sh "short-topic" "ru"
./scripts/validate-notes.sh
```
